Here is a roundup of recent changes that landed in the Ferni repo. We have grouped these updates by area so you can quickly see what changed and how it affects your development work.

## Memory and contacts

We merged several updates to keep memory consistent, private, and respectful across calls.

* **In-memory contact marking:** [#1574](https://github.com/ferni-ai/voiceai/pull/1574) added an `inMemory` field behind the `CONTACT_IN_MEMORY` flag. Account owners can set when a contact has passed away. This turns off proactive check-ins, overdue nudges, or messages to their number, ensuring Ferni speaks about them only in the past tense when guided by the caller.
* **Isolated trigger profiles:** [#1572](https://github.com/ferni-ai/voiceai/pull/1572) fixed a bug where default profile objects were shared across new accounts. Using structured clones prevents data like dates or relationships from leaking into another account's Firestore profile.
* **Unified journal store:** [#1562](https://github.com/ferni-ai/voiceai/pull/1562) introduced a canonical store path behind the `JOURNAL_ONE_STORE` flag. Entries written in the panel or Chronicle now synchronize in one collection instead of living in separate memory stores.
* **Caller memory control:** [#945](https://github.com/ferni-ai/voiceai/pull/945) landed routes at `/api/memories/remembered`. Callers can fetch, delete, or correct the exact active facts used during recall.

## Security and API limits

We landed tighter IP handling, transcription caps, and consent checks.

* **Client IP verification:** [#1538](https://github.com/ferni-ai/voiceai/pull/1538) routed all IP lookups through a single helper. This prevents callers from forging headers to bypass rate limits or access gates.
* **Transcription rate ceiling:** [#1559](https://github.com/ferni-ai/voiceai/pull/1559) added a global limit of 2000 transcription calls per hour via `TRANSCRIBE_MAX_PER_HOUR` to prevent unbounded spend.
* **Family call consent:** [#1568](https://github.com/ferni-ai/voiceai/pull/1568) updated family check-ins behind `FAMILY_CHECKIN_CALLS`. No scheduled calls place unless explicit consent is stored or confirmed.
* **Answer card links:** [#1561](https://github.com/ferni-ai/voiceai/pull/1561) connected delivered media picks directly to `/a/:id` pages. This ensures grounded sources are stored and visible.

## Speed and performance

We landed changes to lower web asset sizes and reduce response latency.

* **Responsive blog images:** [#1592](https://github.com/ferni-ai/voiceai/pull/1592) updated blog graphics to AVIF and WebP formats. This lowered `/blog/` page weight from 12.01 MB to 0.38 MB and reduced total `_site` build output from 698 MB to 166 MB.
* **Non-blocking web scripts:** [#1582](https://github.com/ferni-ai/voiceai/pull/1582) deferred 22 scripts and unblocked font styles, dropping render-blocking items from 37 down to 7.
* **Streaming action guard:** [#1504](https://github.com/ferni-ai/voiceai/pull/1504) added `ACTION_CLAIM_STREAM` to stream replies immediately unless an action is actively requested.
* **Single-session handoffs:** [#1540](https://github.com/ferni-ai/voiceai/pull/1540) turned `MULTI_AGENT_SINGLE_SESSION` on by default, so persona handoffs swap instantly inside one active call.
