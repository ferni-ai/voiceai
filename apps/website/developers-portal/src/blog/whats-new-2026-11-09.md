Here is a roundup of changes that landed in Ferni recently. We grouped these updates to help you see what changed in the codebase and why it matters when you build on Ferni.

## Reliable Session Counts and Spoken Credentials

Catching spoken secrets in memory takes careful handling. In [#2456](https://github.com/ferni-ai/voiceai/pull/2456), we updated memory redaction to catch credentials spoken in everyday speech. The redactor now handles contractions like "my pin's 1234", redacts whole clauses for word secrets, and catches door codes or one-time passcodes sent by text. This keeps spoken secrets out of stored free text and memory facts.

We also cleaned up session counting. In [#2149](https://github.com/ferni-ai/voiceai/pull/2149), we merged a single source of truth for session counts across the prompt, past chats, and journey progress. A call where only a greeting played no longer counts as a session. If a read fails or takes longer than 800 ms, the stored counter stays put so a returning person is never reset to a first-timer.

## Account Erasure and Data Safeguards

Account deletion needs to be completely honest. In [#2885](https://github.com/ferni-ai/voiceai/pull/2885), we fixed account erasure so that if any step fails to wipe data, the process throws an error and keeps the sign-in open. Instead of reporting success while leaving records behind, the app tells the caller that sign-in remains open so they can try again.

Smart home credential saving is also safer now. In [#2918](https://github.com/ferni-ai/voiceai/pull/2918), we landed a fix to fail closed when saving credentials. A transient read error or unopenable sealed envelope now throws an error instead of treating the record as missing and overwriting existing fields.

We also updated our privacy policy and terms page in [#2953](https://github.com/ferni-ai/voiceai/pull/2953). The minimum age requirement is now set to 18 everywhere, and the privacy page lists third-party data providers along with details on Sentry crash reports without linked personal identifiers.

## Platform Tooling and Provider Updates

Google is shutting down the legacy Fitbit API between 2026-10-30 and 2026-11-02. In [#3118](https://github.com/ferni-ai/voiceai/pull/3118), we removed the Fitbit provider across backend routes, settings tiles, and 11 locales so callers will not run into dead connection buttons.

For managing access, [#2043](https://github.com/ferni-ai/voiceai/pull/2043) landed a CLI script for wave 0 waitlist grants. It supports a dry run mode by default and assigns 7-day seats for pending sign-ins when applied.

Finally, offline tooling gained [#2495](https://github.com/ferni-ai/voiceai/pull/2495), which merged an evaluation runner for turn readings. It scores model outputs against golden-set rows with 95% Wilson intervals and latency checks at p50 and p95 without running inside the live agent.
