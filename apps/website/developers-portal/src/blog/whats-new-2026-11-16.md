## Account Deletion and Policy Updates

When someone requests account deletion, every data cleanup step must succeed before closing the account. In [#2885](https://github.com/ferni-ai/voiceai/pull/2885), account erasure now throws an error if any step leaves data behind. It keeps the sign-in active and returns an explicit retry message so the person is not locked out with unfinished deletion. This matters when you build client applications, because failed erasures will no longer close accounts silently.

We also updated our privacy policy on the website to match the iOS 1.0 release in [#2953](https://github.com/ferni-ai/voiceai/pull/2953). The minimum age requirement is set to 18 everywhere, and the policy details crash reporting via Sentry along with third-party data providers.

## Session Tracking and Memory Security

Session counts previously varied across prompts, history views, and backend journey data. In [#2149](https://github.com/ferni-ai/voiceai/pull/2149), we established a single source of truth based on completed calls where the person actually spoke. If a backend read fails or takes longer than 800 ms, stored counters stay intact so returning callers retain their history.

We also expanded memory redaction in [#2456](https://github.com/ferni-ai/voiceai/pull/2456). The redactor now catches credentials spoken naturally in conversation, such as locker combinations, passcodes split by clauses, and secret answers. This keeps sensitive secrets out of stored free text.

Time zone sync logic landed an update in [#3779](https://github.com/ferni-ai/voiceai/pull/3779). The web application now caches time zones only after server confirmation. If a sync request fails due to network drops or pending sign-in status, the app retries on the next launch rather than keeping a stale local zone.

## Integration Safety and Provider Removal

Smart home credential management received fixes in [#2918](https://github.com/ferni-ai/voiceai/pull/2918). Reads that fail or contain unopenable envelopes now throw errors instead of treating records as missing and overwriting existing tokens. Additionally, encrypted fields inside sealed envelopes are properly decrypted using authentic data bindings.

Google is shutting down its legacy API between 2026-10-30 and 2026-11-02. In response, [#3118](https://github.com/ferni-ai/voiceai/pull/3118) removed the Fitbit provider from OAuth paths, status checks, settings tiles, and localizations. Any request sent to the Fitbit endpoint now returns HTTP 400.

## Admin Tools and Evaluation

For managing launch waves, [#2043](https://github.com/ferni-ai/voiceai/pull/2043) introduced the waitlist wave script. It allows dry runs that print counts before applying changes, admitting pending cohorts with 7-day seats for wave 0 while merging duplicate email aliases cleanly.

For model evaluation, [#2495](https://github.com/ferni-ai/voiceai/pull/2495) landed an offline evaluation runner. It measures accuracy against Seth's golden set of turns with 95% Wilson intervals and supports sealed test splits.

Finally, [#2967](https://github.com/ferni-ai/voiceai/pull/2967) fixed visual contrast issues on the iOS resting line by adjusting paper background rendering.
