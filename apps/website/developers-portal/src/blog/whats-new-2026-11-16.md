## Session counts and memory

Different parts of the app used to count conversations in their own ways. That created confusing moments where internal state and history logs showed different totals. In [#2149](https://github.com/ferni-ai/voiceai/pull/2149), we merged a single source of truth for completed sessions where a person spoke. Prompt builders, past chats, and journey progress now read from this shared store. If a server check fails or takes longer than 800 ms, the saved count stays so returning callers never look like first-time visitors.

We also landed memory fixes for spoken credentials in [#2456](https://github.com/ferni-ai/voiceai/pull/2456). When people speak naturally, they might mention passcodes, door keys, or security answers. The redactor now cleans those phrases out of free-text memory while keeping the rest of the sentence intact.

## Account privacy and data safety

Account deletion needs to be completely dependable. In [#2885](https://github.com/ferni-ai/voiceai/pull/2885), we fixed a problem where partial failures during account deletion could close a sign-in anyway. Now, if any cleanup step fails, the deletion process throws an error and keeps the sign-in open. That lets someone try the deletion again instead of leaving orphaned data behind.

Smart home credential storage got a safety fix in [#2918](https://github.com/ferni-ai/voiceai/pull/2918). Read errors used to be treated like missing records, which meant saving updated details could wipe existing settings. The system now fails closed on read errors, preserving stored credentials.

For web connections, time zone updates affect local outreach hours. PR [#3779](https://github.com/ferni-ai/voiceai/pull/3779) landed to ensure the web client caches a time zone only after the server acknowledges it. If a network drop or server error happens, the app will try sending the zone again on the next launch.

## Integrations and system checks

Google closed its legacy API, so we removed the Fitbit integration in [#3118](https://github.com/ferni-ai/voiceai/pull/3118). We cleaned up authorization routes, background services, settings tiles, and localizations across 11 locales. Stripping dead tiles prevents broken sign-in flows and keeps settings clear.

We added management tools for waitlist waves in [#2043](https://github.com/ferni-ai/voiceai/pull/2043). The waitlist command supports dry runs that count pending entries without touching accounts. When applied for wave 0, existing signed-in accounts and pending invites get proper wave status and 7 day seat limits without sending unexpected emails.

To keep build pipelines reliable, [#2319](https://github.com/ferni-ai/voiceai/pull/2319) landed a script that guards configuration files. If a pull request adds changes that silence test failures or bypass standard checks, the build fails automatically until a team member reviews it.

Finally, [#2967](https://github.com/ferni-ai/voiceai/pull/2967) fixed an iOS visual contrast issue on the main screen resting line, making sure resting text remains easily readable across background lighting tints.
